# Basebreaker v1.0

Original 2D endless runner. Black-and-white cyberpunk. Jump and Roll only.

Breach Helix Arc. Keep your flow. Distance and survival score the run. Landscape on mobile.

**[Play live](https://kxz0tn.github.io/basebreaker/)**

## How to play

| Action | PC | Mobile |
| --- | --- | --- |
| Jump | W / ↑ | Swipe up |
| Roll | S / ↓ | Swipe down |

Roll under low lintels. Duck floating panes. A clip is a short stumble. Lasers, pits, fields, and contact kill.

Menus: arrows / WASD, Enter or Space to confirm, Esc to back. Pause: Esc / P. Mute: M.

## Original work

100% original and open source. Vanilla HTML, CSS, and JavaScript. Canvas 2D graphics. Runtime Web Audio. No third-party assets, fonts, samples, libraries, or CDNs.
